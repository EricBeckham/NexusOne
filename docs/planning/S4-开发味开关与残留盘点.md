# S4 开发味开关与残留盘点

基线：`origin/main`（含 S2/S3）。对照 O9 / S1。本卡强化 `devNotesEnabled` 默认关，并列出仍嵌入开发说明的桌面页。

## 开关（默认关）

| 条件 | 结果 |
|---|---|
| 未设置任何开关 | **关**（含 `vite` DEV 服务器） |
| `VITE_NEXUS_DEV_NOTES=true` / `1` | **开**（可覆盖 production） |
| `VITE_NEXUS_DEV_NOTES=false` / `0` | **关**（覆盖 localStorage） |
| `MODE=production` / `PROD` | **关**（除非 env 显式 true） |
| DEV + `localStorage nexus.devNotes=1` | **开** |

实现：`web/src/utils/devNotes.js`。Banner 组件：`NxSourceBanner`（内部调用同一开关）。

**租户演示主路径**（星市 / 已开通 / 发起 / 待办）**无**永久钉死的 `NxSourceBanner`。已开通页的 id / 升级细节块、待办 trace 链接均走 `devNotes`。

## 仍嵌入 `NxSourceBanner` 的页（默认不可见）

|---|---|
| Studio | `FormListView`、`LedgerListView`、`LedgerDetailView`、`LedgerRecordDetailView`、`ReportView`、`ExportWizardView`、`DumpView`、`AuditTraceView`、`NotifyInboxView` |
| Org MFA | `TotpEnrollView`、`RecoveryCodesView`、`EmailMfaView` |

均经 `NxSourceBanner` → `devNotesEnabled`，**未发现**绕过开关强开的桌面实现。

## 其它 `devNotes` 门控（非 Banner）

## 未发现「看起来总开」的桌面残留

S13 已收口部分 studio 反馈；本卡复核后：无桌面页在默认环境下强制渲染 `p3-source-banner`。H5 / `web/src/mobile/**` 不在本波。

## 给演示机

保持 unset `VITE_NEXUS_DEV_NOTES`；勿在共享 `.env` 写 `true`。需要排障时临时 `true` 或 DEV 下 localStorage 后刷新。

## 卡片正文（摘要）

### L1 — 门禁重跑报告
在最新 main（含 K0e）跑 G1/G2 相关测试与关键 `mvn test`，把结果写成短报告（可放 `docs/` 或 PR 说明）。失败须区分：本波回归 / 可选 IT / 环境问题。

### L4 — E2E 手工冒烟
按第五波 §七演示路径走通：订阅开通 → 发起 → 待办审批（含意见）→ 申请结果。断点只记账，不扩 scope 大改。

### L5 — 视觉差距
对照设计规范列出可复现差距；能 1–2h 修的开小 PR；大的只进清单。

### L6 — Demo 隔离
核对 demo seed / demo profile 不会在生产配置默认启用；发现泄漏开小修 PR。

### L7 — 演示 Runbook
文档：开关、账号、种子、点击路径、预期结果；标明演示数据。

### L8 — N 波安全复审
复审密钥是否重启丢失、测试连接是否防内网等已知点；明确小修可开 PR，大的只出清单。

### L10 — 密钥清单
名称、用途、注入方式；**禁止**写入真实密文。

### L11 — 备份恢复步骤
可先 runbook；不要求在本卡内对生产真实演练。

### L12 — Profile 硬化
demo 关闭、暴露面、默认口令等检查；必要小修单独 PR。

### L13 — #270
若仍 open：复审 `chore: drop leftover honesty workflows` 后 squash 合并。

### L15 — 分支清理
列出明显过期个人分支；不确定的只出清单不删。

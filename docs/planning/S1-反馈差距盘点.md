对照：`docs/design/星枢NexusOne_WEB页面设计与前端开发规范_V1.1.md` **§21 Toast / Message / Notification**（及相关：§10 表单错误不得用 Toast；系统级错误用 Error Banner + Trace ID）。  
基线：`origin/main@edbf5e39`（S 波任务卡 #518）。范围：当前 `web/src` **桌面**实现；**不含** `web/src/mobile/**`（H5 不在本波）。  
本卡 **docs-only**，不改运行时代码。承接 O9（`devNotes` / `NxSourceBanner`）与 R/Q 页级空态基建。

## 总览

| 规范通道（§21） | 已对齐（要点） | 未对齐（要点） | 建议 S 波落点 |
|---|---|---|---|
| 保存成功 → Toast | 无共享 Toast；若干页用行内 `notice` | 桌面成功反馈无统一 API；`GlobalHeader` 失败用 `alert()` | **S2** 建共享层；**S6/S11** 接线 |
| 表单错误 → Inline | `ProductStartView` / 模板编辑器等已有字段错误 / `NxRequestAlert` | 部分失败仍可能挤进行内 notice 长文 | 保持 Inline；Toast 不替字段错误（S2 约束） |

| 系统级错误 → Banner+Trace | `NxErrorState` / `NxRequestAlert` 可带 trace | `MarketView` 订阅失败为页内自研条（与 RequestAlert 同构） | 页卡可复用 `NxRequestAlert`；S2 Toast 错误须可复制 Trace |

## §21 对照细则

### Toast（自动消失 3–5s；错误可复制 Trace；禁止堆栈）

| 项 | 现状 |
|---|---|
| 共享组件 / API | **无** `Toast` / `nxMessage` / `ElMessage` |
| 样式 token | 无 Toast 专用 token（颜色可复用 `--nx-success` / danger / info） |
| 冒烟演示 | 无 |

**结论**：必须先有 **S2** 最小共享层，再让 S6/S11 接线。

### 桌面 `alert()`（浏览器阻塞对话框）

| 位置 | 用途 | 规范通道 |
|---|---|---|
| `layout/GlobalHeader.vue` | 切换租户失败、刷新会话失败 | 应为 Toast `error`（或 Error Banner） |
| `mobile/**` | 安装成功等 | **本波不做**（H5） |

### `NxRequestAlert`（页内持久错误条 + 重试/关闭 + Trace）

| 位置 | 用途 |
|---|---|
| `views/market/ProductStartView.vue` | 发起申请提交失败 |
| `views/tenants/FormTemplateEditorView.vue` | 保存/发布失败类请求错误 |

规范归类：偏 **系统级 / 请求级错误 Banner**，不是 Toast。应保留；成功路径不应改用 RequestAlert。

### 页内自研失败条（与 RequestAlert 同构）

| 位置 | 说明 |
|---|---|
| `views/market/MarketView.vue` | `subscribe-failure`：订阅开通失败 + Trace + 重试 |

建议后续页卡改为 `NxRequestAlert` 或共享失败条，避免第三套样式（可挂 Claude S6/S10 旁路，非本卡）。

### 行内 `notice`（成功/提示，常驻段落）

| 位置 | 典型文案形态 |
|---|---|
| `TodoInboxView` | 审批结果说明（含 status 码痕迹） |
| `P4ManagementView` | 「升级请求已完成…」 |
| `ProductDefinitionBindingView` | 保存/绑定成功 + 下一步链接 |
| `FormListView` / `FormStudioView` / `LedgerListView` / `LedgerDetailView` | 发布/提交/CRUD 成功；部分含 record/todo/trace |

规范：短成功应走 **Toast**；带「下一步」的提交后态应走 **S3 Result 壳**（如发起成功）。长调试串不应 Toast。

### `NxSourceBanner`（LIVE 开发说明；`devNotesEnabled`）

组件内 `v-if="enabled"`，`enabled = devNotesEnabled()`。开关：`VITE_NEXUS_DEV_NOTES=true` 强制开；`false` 或非 DEV 强制关；DEV 下仅 `localStorage nexus.devNotes=1` 时开。

**嵌入页清单（桌面，均已 import 组件；演示默认应不可见）：**

| 域 | 视图 |
|---|---|
| Studio | `FormListView`、`FormStudioView`、`LedgerListView`、`LedgerDetailView`、`LedgerRecordDetailView`、`ReportView`、`ExportWizardView`、`DumpView`、`AuditTraceView`、`NotifyInboxView` |
| Org MFA | `TotpEnrollView`、`RecoveryCodesView`、`EmailMfaView` |
| Permission | `PermissionView` |

另：`TodoInboxView` / `ProcessViewerView` / `ReportView` / `ExportWizardView` 等用 `devNotesEnabled()` 控制 trace 链接或旁路说明（非 Banner 组件，但同属开发味通道）→ **S4** 一并盘点。

### 其它

| 通道 | 现状 |
|---|---|
| `NxErrorState` | 列表/页加载失败常用；符合系统级错误方向 |
| `NxEmpty` | 租户主路径已多用；文案去开发味见 Claude S9/S10 |
| 浏览器 `confirm` | Connect 凭证等危险操作；§21 允许 Dialog 类确认 |

## 优先接线动作（供 S6 / S11）

| 优先级 | 动作 | 建议反馈 | 负责卡 |
|---|---|---|---|
| P0 | 星市订阅开通成功 / 失败 | 成功 Toast；失败保持 RequestAlert 类 | S6 |
| P0 | 发起申请提交成功 / 失败 | 成功 → S3 结果壳；失败已用 RequestAlert | S7 / S6 |
| P0 | 待办同意/驳回/撤回 | 短 Toast 或保留短 notice→Toast | S6 |
| P1 | 已开通升级 | Toast success | S6 |
| P1 | 模板保存草稿 / 发布 | Toast；字段错误仍 Inline | S11 |
| P1 | 产品定义保存 / 绑 SKU | Toast 或 S3；现有 notice 可迁 | S12 |
| P2 | GlobalHeader 租户切换/刷新失败 | 去掉 `alert` → Toast error | S2 冒烟后任一页卡或薄 follow-up |
| — | H5 `alert` | 不做 | — |

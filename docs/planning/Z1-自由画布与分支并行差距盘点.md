## 表单：列表 DnD vs 自由画布

### 现状文件

| 文件 | 角色 |
|---|---|
| `web/src/views/tenants/FormTemplateEditorView.vue` | 调色板拖入 + 列表 DnD 排序；`payload().fields` 仅 `key/label/type/required/options` |
| `web/src/views/studio/FormStudioView.vue` | 填报/发布；`pane canvas` 按数组顺序预览草稿字段，无坐标 |

### 差距

1. 无共享 layout 规范化 util（缺省、非法值、整数栅格）。
2. 编辑器无「自由放置」模式（绝对/网格）；列表 DnD 仍是默认且唯一编辑路径。
3. 保存/加载不携带 layout；需确认字段 JSON 能否内嵌（优先），否则 **停并交 Z13**。
4. Studio 只读侧未按 layout 渲染。

### 建议验收句（Z2–Z4 / Z14）

- **Z2**：`normalizeLayout` 对缺省补默认、对非法值收敛；单测覆盖；**不改**拖放 UI。
- **Z3**：编辑器可切换/使用自由画布薄片放置字段；列表 DnD 仍可回退；无对齐线/多选/吸附全家桶。
- **Z4**：保存后再打开 layout 仍在；若必须新列则 PR 停写并点名 Z13。
- **Z14**：含 layout 时 Studio 只读按坐标/网格预览，否则回退列表。

## 流转：顺序流 vs exclusive / parallel

### 现状文件

| 文件 | 角色 |
|---|---|
| `web/src/views/studio/ProcessViewerView.vue` | 文案：「不支持分支与并行」；可编辑类型仅 start/userTask/end |
| `web/src/views/studio/processDraft.js` | `serializeDraftXml` 认识 `exclusiveGateway`；`addDraftNode` 非起/用户/结束则抛「仅支持开始、用户任务和结束节点」；测例断言拒绝网关 |
| `web/src/views/studio/sequentialFlow.js` | 网关/条件/多出边 → 非顺序，编辑器只读 |
| `web/src/views/studio/processLayout.js` | 按 BFS 深度分列自动 `{x,y}` |
| `nexus-p3-studio/.../ProcessDefinitionDraftService.java` | 存取 `bpmn_xml`；**无**网关结构校验 |
| `nexus-p3-studio/.../V551__process_definition_draft.sql` | `bpmn_xml text`；无独立节点类型列 |

### 差距

1. FE 不能增删 `exclusiveGateway` / `parallelGateway`。
2. 条件边：数据结构有 `flow.condition` 与 BPMN `conditionExpression`，缺选中边编辑 UX（Z7）。
3. 布局对网关扇出可读性不足（Z8）。
4. BE 不校验网关/并行合法性；契约测薄（Z11/Z12/Z15）。
5. 非顺序错误文案偏开发味（Z10，对齐 S）。

### 建议验收句（Z6–Z12 / Z15）

- **Z6**：可增删 `exclusiveGateway`；`processDraft.test` / Viewer 测更新。
- **Z7**：选中边可编 `condition`；空条件允许。
- **Z8**：gateway 多出边扇出排版可读；单测；无第三方图编辑器。
- **Z9**：`parallelGateway` 增删 + 序列化；fork/join 约定写清。
- **Z10**：非法结构错误贴节点或汇总，去开发味。
- **Z11/Z12**：草稿含 exclusive / parallel 时校验通过或明确错误。
- **Z15**：validate HTTP/契约测摘录通过命令。
- **Z13**：仅当 JSON/`bpmn_xml` 不够时 Flyway；否则 schema contract「无需迁移」。

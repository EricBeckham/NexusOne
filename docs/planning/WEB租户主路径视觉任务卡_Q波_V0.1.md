## 卡片正文（Q）

### Q1 — 表密度 token

对照规范表格行高/表头，把演示租户列表依赖的行高、单元格 padding 收到共享 token 或薄 table 样式。PR 写影响面。禁止改列数据与接口。

### Q2 — 分页 / 列表底栏

统一分页或列表底栏的间距、禁用、当前页观感。若仓库已有组件则对齐样式；没有则最小可用组件，先接 1 个试点列表。

### Q3 — Skeleton 扩到租户列表

在 `TodoInboxView` 与另 1 个租户列表（建议 `MarketView` 或 `P4ManagementView`）接入已有 Skeleton；其余页留给后续。

### Q4 — 状态标签统一

租户主路径列表上的状态色/字重/高度统一到共享标签；兼容现有调用。PR 列出改到的视图。

### Q5 — 租户页眉槽位

提供共享页眉/面包屑区域样式或薄组件（标题 + 可选说明 + 右侧操作槽），不改路由。供 Claude 页卡接入。

### Q6 — Q 波打勾记账

更新/新建 `docs/planning/Q6-Q波打勾记账.md`：Q1–Q11 勾选；附主路径截图路径。docs-only。

### Q7 — 星市目录页观感

`MarketView` / `MarketHomeView`：卡片间距、标题层级、状态角标；Filter 区保持 O10 方向。不大重构业务筛选。

### Q8 — 已开通管理页

`P4ManagementView`：接入 Q5 页眉；保持 O11「一卡一 Primary」；升级等次要操作区间距与对齐。

### Q9 — 发起申请页

`ProductStartView`：字段间距/必填星/错误全面走共享样式；底部取消 + 单一 Primary；需要时 sticky 底栏。禁止改提交接口语义。

### Q10 — 待办箱

`TodoInboxView`：空态 `NxEmpty`（原因+下一步）；状态用 Q4；加载用 Q3；行密度用 Q1。不改审批业务规则。

### Q11 — 我发起 / 我的申请

对应列表或 Tab：与 Q10 同一空态/加载/页眉标准。若「撤回」等行为属既有产品规则，本卡只动视觉，不动行为开关。

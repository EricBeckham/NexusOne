# 快进并行任务看板 V0.1

> **文档状态**：草案（随冻结表执行；第一期边界已按 Eric 确认）  
> **依据**：`docs/planning/快进P4P5_范围冻结表_V0.1.md`（含星联仅自用、第一期登录优先）  
> **冲突区业主**：Flyway 号段、PolicySnapshot/权限内核、租户拦截器、五产品壳路由表 — 单写，他人只消费接口。

---

## 总规则

1. 波次串行出门；同波内按车道并行（建议同波 ≤4 个 PR 并行）。
2. **第一期只验收自己用户登录**，不验收开发者门户 / 外部 OAuth / 薄 P5。
3. Defer / Out 禁止「顺便做」进并行车道。
4. **备份/恢复整包不进任何波次车道**（含第一期）；先正向主路径。

---

## 第一期（当前）— 自己用户登录

**出门**：租户用户用自己账号登录成功 → 会话可用 → 进入五产品壳之一；失败路径可理解。  
**明确不做**：开发者门户、外部 OAuth 客户端生态、对内开放 API 门禁、Webhook、连接器。

| 车道 | 目标 | 非目标 | 依赖 | 建议 PR 标题 | 验收一句 |
|---|---|---|---|---|---|
| L0 | 租户上下文可挂到请求（最小隔离可用） | 完整生命周期运营台 | — | `feat(p1): request tenant context for login path` | 登录后请求带租户且不串租户 |
| L1 | 账号/人员主数据最小面（能被认证主体关联） | 人员生命周期边角、个人中心大而全 | L0 | `feat(p2): account person master for login` | 存在可登录的人员账号记录 |
| L2 | **Keycloak 自己用户登录 + 会话**（第一期核心） | 外部 IdP 细项、SMTP 花活、外部 OAuth | L1 | `feat(p2): keycloak user login and session` | 浏览器完成用户名密码登录并保持会话 |
| L3 | 登录后进入产品壳（星域/星权/星构入口可点） | 业务页做全、leftover 当正式 IA | L2 | `feat(ui): post-login product shells entry` | 登录后进入壳，三入口可达空壳页 |

**合入顺序建议**：L0 → L1 → L2 → L3（L3 前端可与 L2 后半并行）。

## 禁止并行（会抖）

- 两人同时改 PolicySnapshot / DataScope 实现或同一 Flyway 号段  
- 第一期未出门就开 P4 SKU、P5 对内 API，或任何外部 OAuth / 开发者门户  
- 把 S2 / Defer 项塞进「顺便」
- 备份、恢复、RecoveryPort 真恢复、产品级 HA/RPO

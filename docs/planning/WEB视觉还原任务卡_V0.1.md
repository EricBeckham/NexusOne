# WEB 视觉还原任务卡 V0.1

- 基线：`main@50f4e40`（P4 管理子页已合入，PR #293；第二波 X0–X3 / B1 与壳 W0–W5 已合入）
- 依据：`docs/design/星枢NexusOne_WEB页面设计与前端开发规范_V1.1.md`（**确定**）；`docs/design/references/web/` 五张首页效果图；`docs/planning/screenshots/w5/`（W5，略旧）；2026-09-24 对照 `origin/main` 代码与本地 Vite 活截
- 范围：桌面 WEB **视觉还原 V 波**（token / 共享 Dashboard 积木 / 壳层 Icon / 五产品已有页布局对齐）。**不新建** §28/§29 仍标 later 的功能子页（交第二波 X4/X5）；**H5 整波延后**
- 执行方：本地 Codex、Cursor 等按卡领取；NexusOne 只负责拆分与审阅
- 数据原则：页面**只展示真实数据**；空态一律「暂无」。演示种子**单独成卡**，默认关闭，禁止打进生产

## 默认决策（可改）

1. **一卡一产品一薄片**：前端 / 后端分卡；需新表或迁移的单独成卡；安全敏感单独成卡。
2. **先对齐已有页**：本波只还原已挂路由的页；P4/P5 later 子页功能仍归 X4/X5。
3. **不编造数字**：无聚合 API 则整卡「暂无」；禁止把效果图假数写进前端。
4. **V1 拆两卡**：V1a 提供 KPI/面板/空图表位；V1b 提供健康/活动/待办列表积木。
5. **种子按产品拆**：先 V-SEED-0 开关与文档，再 V-SEED-P1…P5 各产品最小行；P5 不得植入可用真实密钥。

## 所有任务通用约束

- 每个任务从最新 `origin/main` **新开分支 + 独立 worktree**；**禁止**在有人占用的 `D:\NexusOne` 主工作区直接改；**禁止**动 Codex worktrees。
- **一卡一 PR**；PR 只含本卡改动。
- UI 卡（V0 / V1a / V1b / V2–V13）：只改 `web/src`，**排除** `web/src/mobile/**`；不改后端。
- 种子卡（V-SEED-*）：只改后端 seed / `scripts/` / 文档；默认关闭；**禁止**作为正式镜像默认入口。
- 原有深链必须仍可打开（同路径或显式 redirect）。
- 交付前必须通过：
  - UI：`npm test`、`npx vite build`、`npm run assert:h5`、`npm run assert:h5-every-page`、`git diff --check`
  - 种子：相关模块测试绿；文档含启用/清理；租户隔离冒烟
- 页面不编造业务数据；空列表 / 空 KPI 显示「暂无」。

## 3. 任务卡正文

### V0 — 全局 Design Token 对齐与平台底色

- **类型**：前端　**前置**：无　**分支**：`ui/v0-tokens-platform-bg`
- **目标**：`tokens.css` 补齐规范 §2 缺口；平台模式不再整页奶油底；标题阶梯接近 28/16/14。
- **区域**：`web/src/styles/tokens.css`；壳层平台背景样式；必要时 `NxPageHeader`。
- **验收**：`--nx-chart-*`、P3/P5 secondary、`--nx-shadow-dialog`、页标题字号 token 存在并被使用；平台模式背景为页底色或侧栏色+条带提示，而非整页 warning-light；UI 门禁全绿。
- **可并行**：V-SEED-0。

### V1a — Dashboard 积木：KPI 行 + 面板卡 + 空图表位

- **类型**：前端　**前置**：V0　**分支**：`ui/v1a-dashboard-kpi-panel`
- **目标**：新增共享 `NxKpiRow`、`NxPanelCard`、空图表占位（无数据不画假线；图表库可懒加载或仅占位）。
- **区域**：`web/src/components/**`、组件单测；可选 dev gallery。
- **验收**：gallery/单测可见 KPI 行与面板；无任何写死业务数字；约 1–2h 可审 PR。
- **可并行**：V1b、V2。

### V1b — Dashboard 积木：健康列表 + 活动时间线 + 待办列表

- **类型**：前端　**前置**：V0　**分支**：`ui/v1b-dashboard-lists`
- **目标**：新增共享 `NxHealthList`、`NxActivityTimeline`、`NxTodoList`（空态「暂无」）。
- **区域**：`web/src/components/**`、组件单测；可选 dev gallery。
- **验收**：三块积木可独立渲染空/有数据插槽；无业务假数；约 1–2h 可审 PR。
- **可并行**：V1a、V2。

### V2 — 壳层 Icon 与顶栏视觉

- **可并行**：V1a、V1b。

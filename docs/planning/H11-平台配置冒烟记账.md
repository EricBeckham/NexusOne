# H11 平台配置冒烟记账

日期：2026-09-25。基线：`origin/main@a879c97`（H10 #432 已合入）；分支：`codex/h11-platform-config-smoke`。只记浏览器与后端事实，不改产品范围或业务代码。

## 环境

- JDK 21、Maven 3.9.11 在本 worktree 执行 `mvn -DskipTests package -q`，退出码 0；Web Vite 启动成功。
- 本 worktree 内新建 PostgreSQL 15.18 空集群，监听 `127.0.0.1:55437`，使用其中的空 `postgres` 库；未接触已有 `nexusone` 或 `5432`。
- 后端 `demo` profile、stub IdP、IAM / permission JDBC，并仅为本地平台页面打开 `NEXUS_P1_DEMO_CONTEXT_ENABLED=true`；这不是 `prod` 验收配置。浏览器使用本地 stub 平台操作头检查 P1 页面，另用演示种子林晓身份检查 P4 产品定义页。没有真实口令写入仓库。

## 逐步结果

| 步骤 | 结果 | 证据 / 断点 |
|---|---|---|
| 打开平台表单模板 | 通过 | 星域「表单模板」列表可读，显示种子 `demo_simple_approval`，状态「已发布」、2 个字段；编辑页能打开并预览「事由」「审批人」。 |
| 新建模板并保存草稿 | **阻塞** | 在 UI 新建 `h11_smoke_template`，添加必填文本字段 `subject`，点击「保存草稿」后显示 `Internal error`，Trace ID `01a0d862-78d8-78e7-8410-92779d722758`。后端 `FormTemplateDraftService.create:61` 对 `platform.form_template` INSERT 抛 `BadSqlGrammarException`；根因 PostgreSQL JDBC `PSQLException: 无法推测实例 java.time.Instant 的 SQL 类型`。没有创建成功。 |
| 校验 / 发布 | **阻塞** | 尝试在已有种子模板点击「发布」，页面提示 `publish requires VALIDATED template status`；随后点击「校验」也显示 `Internal error`，Trace ID `01a0d863-390c-7046-a1b8-e2782d1415cd`。后端 `FormTemplateDraftService.validateDraft:104` 更新 `updated_at` 时再次因 `Instant` SQL 类型无法推断而失败。故不能生成本次新发布版本。 |
| 绑定产品 | 未完成 | 星市「产品定义」页在林晓租户身份下能打开，列表显示种子 `demo_simple_approval` 为 `PUBLISHED`，已发布流程下拉有 `demoSimpleApproval · 版本 1`；但「已发布模板版本」下拉显示「暂无」，保存按钮禁用。没有本次新发布模板可选，也没有执行绑定。使用任意本地 stub 平台操作员而无租户身份时，此页另返回 `TenantContext is required`；该身份不能代替租户上下文。 |

## 结论与收尾

平台配置主路径**未通过**：新建与校验均被 `Instant` JDBC 持久化错误挡住，发布及新产品绑定不能继续。种子模板可读、产品定义页面可打开不等于新模板已发布或已绑定。产品定义页无可选已发布模板版本亦是需要后续复核的独立 UI / 数据断点；本卡不推断其根因、不改业务代码。

本次后端、Web 与一次性 PostgreSQL 已停止，H11 的数据库集群 / 日志已清理；构建工具和隔离 Maven 缓存仍在本 worktree，供随后 H12 使用。

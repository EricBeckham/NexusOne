| 轴 | 现况（main） | CF 加深方向 |
|---|---|---|
| **表单定义** | `FormTemplateEditorView` 字段列表+属性；校验/发布可用 | 属性分区 Tab、字段类型说明、预览申请人视角、密度对齐 §18 |
| **流程定义** | `ProcessViewerView` 顺序/自由画布已有 ZA 加深 | 属性面板分区、校验结果人话、发布确认信息架构；**不**重开高级 BPM 大产品 |

## 3. 四轴能力说明

### 3.1 表单定义（Form）

- 现状痛点：属性区扁平；申请人预览弱；字段类型错误提示偏技术
- 加深：
  - 属性面板 Tab：`基本 | 校验 | 权限(只读说明) | 外观`
  - 「申请人预览」只读抽屉（非第二编辑器）
  - 校验失败锚定字段 + S Toast/`NxErrorState`
- **不做**：自由画布重做（Z/ZA 已覆盖画布对齐）；运行时填报大改

### 3.2 流程定义（Process）

- 现状痛点：大页；校验/发布信息架构挤；硬色残留（见 UI 审核）
- 加深：
  - 右侧属性分区（节点基本 / 审批人 / 条件摘要）
  - 校验结果列表可点击定位节点
  - 发布确认框：影响范围（版本号/是否已有产品引用）诚实展示
- **不做**：会签/或签/加签转交/子流程产品化；重写整个设计器

### 3.3 模板定义（Template = 平台表单模板治理）

- 与「表单定义」重叠但偏**平台治理**：列表版本徽章、发布态、被哪些产品引用（只读）
- 加深：列表「引用中」计数；编辑器顶栏版本/状态；空态 CTA 与向导一致
- **不做**：模板市场、跨租户模板商店

### 3.4 打印配置（Print）

- PC 波：最小样例打开+预览壳
- CF 波：`字段 → 打印槽位` 映射表 + 纸张尺寸枚举 + **只读 HTML/PDF 预览**（可静态）
- **完整设计器（拖拽排版/页眉页脚引擎）标 later**，单卡注明，不进本波默认队列
- Flyway：优先静态样例/现表；必须迁移 → V706+ 专卡

## 卡片正文（O）

### O1 — 规范差距盘点（文档）

对照规范 §2（token）、§9（按钮）、§10（表单）、§11（筛选）、§12（空态）、§22（加载）与当前 `web` 实现，输出 `docs/planning/O1-规范差距盘点.md`：已对齐 / 未对齐 / 建议落点文件。不改产品代码。

### O2 — 全局表单间距 token

把演示主路径表单依赖的字段垂直间距收到共享 token 或共享 class；避免每页魔法数。PR 说明写影响面。禁止改提交逻辑。

### O3 — 按钮高度与 Primary 约定

按钮默认高度贴近规范 34/36；文档化「一个操作区一个 Primary」。提供共享类或组件 props，供 O11 等使用。

### O4 — 必填星与字段错误

共享样式：必填红 `*`、错误文案紧邻字段。不强制本卡改完所有历史页；至少打通一处示例 + 导出供 Q/R 复用。

### O5 — NxEmpty 对齐

空态组件支持：简短原因、下一步行动槽。兼容现有调用点，避免大爆炸改名。

### O6 — Skeleton 最小集

列表行骨架 + 表单块骨架各一；先在 1 个试点页接入（PR 写明），其余页留给 Q/R。

### O7 — 壳层顶栏与内容宽

顶栏品牌/标题区统一；主内容最大宽度与规范一致（或规范允许的演示值）。不改路由结构。

### O8 — 侧栏密度

导航项高、字重、选中态、分组；去掉拥挤或「开发菜单」感。

### O9 — 去开发味 Banner

演示主路径默认不展示源码/API 调试 Banner；`import.meta.env.DEV` 或显式 flag 下可开。

### O10 — 星市 FilterBar

目录筛选不要包在沉闷大 Card 里；保持筛选可用，视觉贴近 §11。

### O11 — 已开通双 Primary

「发起」保留主按钮；「提交升级」等降为 secondary/文案按钮，避免一卡两主色。

### O12 — O 波打勾记账

更新差距盘点：O2–O11 哪些已勾；附主路径截图路径。docs-only。

# O1 规范差距盘点

对照：`docs/design/星枢NexusOne_WEB页面设计与前端开发规范_V1.1.md` §2 / §9 / §10 / §11 / §12 / §22（空态相关另见 §23，供 O5 对照）。  
基线：`origin/main@fa18a036`（O 起任务卡已合）。范围：当前 `web/` 桌面实现；**不含 H5**、自由画布、分支/并行 BPM。  
本卡只文档，不改产品代码。承接 L5 记账与 N 波主路径补强。

## 总览

| 章节 | 已对齐（要点） | 未对齐（要点） | 建议 O 波落点 |
|---|---|---|---|
| §2 Token | 颜色 / 产品色 / 间距阶梯 / 阴影大部分在 `tokens.css` | 表单项竖距、按钮高度未进 token；圆角 token 不全 | O2、O3 |
| §9 Button | `.primary` / `.ghost` / `.danger` 三层存在 | 默认高度未钉 34/36；多 Primary；无共享 Button 组件 | O3、O11（Claude） |
| §10 Form | 发起页/模板编辑器局部红星+贴字段；720px 局部 | 全局 `.nx-field` 竖距 12px；无共享必填/错误类 | O2、O4 |
| §11 Filter | 目录有筛选条雏形 | 仍落在大块布局内；无 `NxFilterBar` | O10（Claude） |
| §12 Table | `NxStatusTag` 有；部分空态用 `NxEmpty` | 无 `NxDataTable`；行高未 token 化；部分表内「暂无」 | Q/R + O5 复用 |
| §22 Loading | 按钮禁用文案局部有 | 无 Skeleton；页加载多为文案 Spinner | O6 |

## §2 Design Token

### 已对齐

| 项 | 证据 |
|---|---|
| 全局色板、产品色 `[data-product]` | `web/src/styles/tokens.css` |
| 4px 间距阶梯 `--nx-space-1`…`--nx-space-10`（含 20px=`--nx-space-5`） | 同上 |
| Card 阴影 / 部分圆角 | `--nx-shadow-*`、`--nx-radius` / `--nx-radius-sm` |
| 系统字体栈接近规范 | `--nx-font` |
| 共享组件禁硬编码色（抽检） | `web/src/components/componentTokens.test.js` |

### 未对齐

| 项 | 现状 | 建议落点 |
|---|---|---|
| 表单项垂直间距 20px | `.nx-field { margin-bottom: 12px; gap: 6px }` | **O2**：`--nx-form-field-gap` / `.nx-field` 改用 space-5；PR 写影响面 |
| 按钮默认高度 34/36 | `.primary`/`.ghost` 仅 `padding: 8px 12px`，无 min-height | **O3**：`--nx-control-height` + 按钮类 |
| 圆角 4/6/12/16 全集 | 有 sm/默认/pill，缺显式 4px / 16px token 名 | O2/O3 顺手或后续 Q |
| Card 内边距 | `.nx-card { padding: 20px }` 硬编码，未用 `var(--nx-space-5)` | O2 可顺带 |
| 字号阶梯不全 | 缺 Section 18px、Card 标题 16 独立 token 等 | 非 O 波阻塞，记 Q |

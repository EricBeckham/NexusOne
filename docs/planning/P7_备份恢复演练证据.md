## 3. 命令摘要

演练通过本机 loopback PostgreSQL 管理连接执行；认证由本机 PostgreSQL 配置处理，命令中没有口令。下面只记录可审计的命令形态，不记录任何认证材料：

```text
createdb <专用来源库>
psql <专用来源库> -c "CREATE SCHEMA ...; CREATE TABLE ...; INSERT ...;"
pg_dump --format=custom --no-owner --no-privileges --file=<worktree内临时dump> <专用来源库>
createdb --template=template0 --encoding=UTF8 <专用恢复库>
pg_restore --dbname=<专用恢复库> --exit-on-error --no-owner --no-privileges <worktree内临时dump>
psql <来源库/恢复库> -c <schema、行数与标记读回查询>
dropdb <专用来源库>
dropdb <专用恢复库>
```

dump 和所有临时脚本 / 输出只位于 `D:\Projects\NexusOne-codex\.p7-drill`，验证结束后从 worktree 清除。

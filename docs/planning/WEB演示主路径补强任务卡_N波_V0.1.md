## 卡片正文

### N1 — 星市主路径观感薄片

**范围**：目录、已开通、发起页（演示租户主路径前半段）。

**要求**：

- 对照 `docs/design/星枢NexusOne_WEB页面设计与前端开发规范_V1.1.md` 与 L5 记账，收 1–2 小时内能合的间距 / 按钮层级 / 主次操作区分。
- **不要**大拆 FilterBar 整页布局；不要整站 token 改动。
- 一卡一 PR。

### N2 — 待办箱状态与空态

**要求**：

- 待办 / 我的申请 / 已办：空态有解释与下一步；状态展示用词与颜色在三处一致。
- 不改撤回等 K18 行为语义。
- 一卡一 PR。

### N3 — 模板编辑器表单规范薄片

**要求**：

- 平台表单模板编辑：必填红色 `*`、校验/保存错误贴近字段、保存/校验进行中禁用防重复提交。
- **禁止**自由画布、栅格布局编辑器、新字段类型大爆炸。
- 一卡一 PR。

### N4 — 流转配置顺序流可读性

**要求**：

- 顺序节点列表/编辑区更可读；无节点或未保存时有空态说明。
- **禁止**分支、并行、自由画布。
- 一卡一 PR。

### N5 — 审批状态字段对齐

**背景**：M1 已修前端提示横线；若列表/详情仍缺权威 status/outcome，查清是 API 未返回还是前端未读。

**要求**：

- 本机 demo：同意后提示、已办、我的申请三处状态一致且来自真实字段。
- 若需补 API，只做最小返回字段，不改审批业务语义。
- 一卡一 PR；PR 说明写清根因（FE / API）。

### N6 — 模板校验错误可定位

**要求**：

- 平台模板校验/发布失败时，调用方能知道哪个字段或哪条规则失败（结构化错误或稳定 message）。
- 可只做后端契约 + 最小前端展示；不扩新校验规则引擎。
- 一卡一 PR。

### N7 — 产品定义下拉空态

**要求**：

- 「已发布模板版本」/ 流程选择：无数据时说明原因与下一步；有数据却禁用时写清原因。
- 优先前端；若字段/API 对不齐则最小修复。
- 一卡一 PR。

### N8 — 演示主路径冒烟记账（可选）

**前置**：建议 N5–N7 已合，且 Claude 至少 N1/N2 已合（或注明未合项）。

**要求**：

- 本机 demo 空库浏览器（或既有 HTTP 等价）跑：订阅→发起→审批含意见→我的申请；平台侧点验模板编辑/绑定相关页观感与错误可读性。
- 记账 `docs/planning/N8-演示主路径冒烟记账.md`；断点只记账；**不宣称外网/真 Keycloak**。
- 一卡一 PR；可跳过若 Eric 明确不需要本波记账。

## 0. 快进策略一句话

**先做薄 S0+S1 核心闭环（P1–P3）→ 跳过/后置几乎全部 S2 → 上薄 P4（S3 核心）→ 再上薄 P5（S4 核心）。**  
S3 之前继续用**平台预置默认权益包**；切到 P4 订阅后再把商业真相源交给星市。

UI 约束：从本冻结生效起，新页面必须按已确定的 WEB/H5 规范与五产品壳落地，不再扩验收壳/leftover 主入口。

## 2. 可暂缓（Defer）— 不挡「先摸到 P4/P5」

### 2.1 整阶段后置

| 范围 | 处理 |
|---|---|
| **P1–P3 几乎全部 S2**（治理、迁移、代管、高级搜索过滤、规则引擎产品化、流程运维高级等） | 整体后置于薄 P4 之后或并行小队 |

### 2.2 模块级暂缓清单（优先扔到后面）

## 3. 明确不做（Out）— 本快进波次声明不做

与规格 M0/排除项对齐，本波次**不排期、不验收为产品能力**：

- 全局搜索、完整 BI/报表产品化  
- Kafka / OpenSearch / 独立 API Gateway / Kubernetes 强依赖  
- 单租户逻辑恢复、隔离模式升级为独立库集群（作为主路径）  
- 高级 ABAC；会签/或签/加签/减签/流程迁移  
- 邮件/短信**业务**通知（Keycloak SMTP 仅部署需要可配）  
- 信创组合穷举；等保/密码机/通算全量交付宣称  
- 把 leftover 诚实页当五产品正式 IA

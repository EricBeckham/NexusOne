## 执行环境与交接规则

- 数据库：本机 PostgreSQL 15，`localhost:5432`，账号 `postgres`。密码由领取人经本机环境变量或受控 Secret 输入；**不写入 Git、Issue、命令示例或测试报告**。业务开发另建最小权限账号，避免长期使用超级用户。
- 缓存：本机 Redis 3.2，`localhost:6379`。P0-05 契约已在本机跑过；不要把 Redis 8 候选 PoC 当成新的领取任务。
- 运行：Java 服务在本机作为 JAR/本机进程运行；禁止 Docker、Compose 和容器依赖。Java 21 / Boot 4.1.1 是产品基线。
- 工作方式：只领取上表未关闭的 S0+S1 余量。填写负责人、评审人、代码目录、依赖、验收证据链接。不要把 M0-01～12 重新分给新人“再实现一遍”。
- 双数据库与信创差异：两份 V1.1 基准文档仍有 GaussDB-only 要求。当前用户指定 PostgreSQL-only 执行，因此仅能报告 PostgreSQL 范围的结果；正式发布门禁另行修订基准口径后认定。

## 只记账，本卡不改

- **目录筛选包在大 Card 里**（`MarketView.vue`）。§11 要求 FilterBar 不要用大片 Card。拆工具条会动整页目录布局。
- **P4 首页 / 目录眉题仍是 `P4 · NEXUS MARKET`**，管理页和发起页是「星市」。统一品牌要改首页、目录、导航，超出本卡。
- **安装升级 stepper 是静态文案**（`P4ManagementView.vue`）。§28.6 要的是 Precheck → Verify 的真实步骤状态；现在每张卡都画同一排字，兼容范围 / Schema / 迁移也是「暂无数据」。
- **同一张已开通卡上有两个 Primary**：「发起」和「提交升级」。拆操作区要重排升级表单。
- **待办空表仍是单元格里的「暂无」**（`TodoInboxView.vue`）。§12.5 要图标、解释、下一步。改成 `NxEmpty` 会换掉 K18 的表格结构。
- **「我发起」仍保留撤回**。第五波 K18 写的是本波隐藏撤回；产品申请箱没有撤回。动撤回属于 K18 行为，不在本卡。
- **全站创建表单没有统一红色必填星**（例如模板编辑器用普通 ` *`）。只修了发起页。
- **全局 `.nx-field` 间距仍是 12px**，按钮高度也没进 token。改 `tokens.css` 会扫到所有页。
- **页面加载仍是文案，不是 Skeleton**（§22.1）。发起页、目录、待办都这样。
- **待办 / 台账等页仍挂开发者 `NxSourceBanner`**。K18 #393 已把「意见字段 API 未提供」改成意见会写入任务评论；本卡不再改这句。
- **H5 待办详情仍写「意见（仅本页，API 无 comment 字段）」**（`web/src/mobile/.../TodoDetailPage.vue`）。第五波整波不做 H5。
- **订阅表「权益状态」固定「暂无投影读模型」**。缺读模型，不是样式问题。

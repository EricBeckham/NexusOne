## 双主路径判定（本机空库）

| 路径 | 结论 | 依据 |
|---|---|---|
| 平台配置主路径 | **通过（本机 demo 空库）** | [J3 记账](J3-平台配置冒烟记账.md)（浏览器）：新建模板 → 校验 → 发布 → 绑产品。I9 的 `platform.audit_event.tenant_id=null` 断点已由 I7 #447 / [J1 #448](https://github.com/EricBeckham/NexusOne/pull/448) 消除。[J3 后复验](NexusOne-J3后空库复验记账.md)（#453，HTTP）：首启空库 create→validate→publish→bind 再绿；#451 后种子流程 `demoSimpleApproval` 可直接选用，无需 UI 补发流程。 |
| 租户订购使用主路径 | **通过（本机 demo 空库）** | [I8 记账](I8-手工冒烟记账.md)：订阅 → 发起 → 审批含意见 → 我的申请。J3 后复验（#453）同源 stub 身份再跑一遍：林晓订阅/发起，周然 `APPROVE` 并回写意见，林晓「我的申请」status=`APPROVED`。I1 后发起 `Instant` 错误未复现。 |

整体：**本机双主路径已绿**，可作为「演示 / 内测本机可走通主路径」的门禁依据。非阻断展示项（如 I8 审批成功提示 `approval_status=—`、无租户会话读流程草稿 401 的前端文案）归 M 波其它卡，**不**推翻本机路径通过结论。

## 边界（强制写清）

下列结论**仅**覆盖本机：

- Profile：`demo`；IdP：**stub**（种子身份林晓 / 周然）；平台头：`NEXUS_P1_DEMO_CONTEXT_ENABLED=true` 的演示 actor。
- 数据库：一次性空 PostgreSQL 15.x（未连已有 `nexusone` / 共享 `5432`）。
- 驱动：浏览器冒烟（J3）或同源 HTTP（J3 后复验 / 自动化测试）。

**不宣称**：

- 外网演示机已部署（无获授权主机、DNS/TLS、专用库凭据、稳定主密钥注入）。
- 真实 Keycloak 已验收（realm/client/issuer/redirect/受控账号联调未做；见后续 M7 清单）。
- 公网商用首发或生产环境门禁已关。

## 本机 `prod` 等价启动（仍有效）

初版 I10 在 `main@ba8c706` 对本机干净库跑过 `ProductionProfileGuardTest` + `NexusOneProdProfileBootTest`（共 10 tests 全绿），证明 [P6 清单](../engineering/runbooks/demo-host-prod-deployment.md)对应的**本机 `prod` profile 启动 + Flyway**。该项与双主路径 demo 冒烟相互独立：前者不替代 stub 主路径验收，后者不替代真机部署。测试用 `.invalid` issuer 与测试密钥**不能**用作部署值。

外部仍缺：外网主机授权、DNS/TLS、密钥管理器中的真实 `NEXUS_CRYPTO_MASTER_KEY`、真实 Keycloak confidential client。缺项闭合前只允许做 env 模板 / JAR 校验脚本 / Keycloak 验收清单（M6/M7），**勿写「已部署」**。
